# PPU golden cases: <name> <ROM relative to tests/corpus> <frame> [max-diff=N] [KEY:FIRST-LAST ...]
#
# <name>.png is mGBA's picture at <frame> (tests/oracle/make-ppu-goldens.py). The test runs the ROM in
# the AnyGBA interpreter and passes when one of its frames <frame>-12 .. <frame>+2 is identical: the PPU
# must be pixel exact, but CPU timing is not cycle accurate, so the same picture can arrive a few frames
# apart (mGBA's start-up alone runs about six frames later than AnyGBA's for these ROMs).
# max-diff=N allows N differing pixels where the reason is documented here and is not the PPU.
# oracle-darken-rounding accepts red/green one step brighter than mGBA in darkened areas: mGBA's
# RGB565 renderer (the libretro build) rounds those two fields differently from blue; AnyGBA uses
# c - (c*EVY >> 4) for all three channels.
