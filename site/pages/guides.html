Install

AnyGBA produces C code and compiles it on your machine, so you need a C/C++ toolchain as well as the AnyGBA package:

SystemPackageAlso install
Windows x64anygba-v{{version}}-windows-x64.zipVisual Studio 2022 (Desktop development with C++), CMake 3.28+
Linux x64anygba-v{{version}}-linux-x64.tar.gzGCC 13+ or Clang 16+, CMake 3.28+, SDL development packages
macOS arm64anygba-v{{version}}-macos-arm64.tar.gzXcode command-line tools, CMake 3.28+

Extract the archive anywhere; the folder you extract to is the prefix, and the tools are in its bin/ folder. To build AnyGBA from source instead, see Build in the README.

Convert a game

Dump the ROM from a cartridge you own (see the FAQ), then run one command:

<prefix>/bin/anygba build game.gba -o dist

This recompiles the ROM to C, compiles it against the runtime, and writes:

SystemOutput
Windowsdist/<Title>.exe
Linuxdist/<Title>
macOSdist/<Title>.app (ad-hoc signed)

The ROM is embedded in the program, and the program checks the ROM's SHA-256, so it only ever runs that one game. Because it contains the ROM, share it only with people who own the game. All build options are on the Tools page.

Run a game

<Title> [--scale N] [--fast] [--save-dir DIR] [--input FILE]
  • --scale N sets the window size as a multiple of 240×160 (default 3).
  • Hold Tab to fast-forward.
  • <Title> --help lists every option; see also the game options.

Saves

The save chip (SRAM, Flash 64/128 KB, EEPROM 512 B/8 KB) is detected from the ROM. Saves go to:

SystemFolder
Windows%APPDATA%\anyport\anygba\saves\
Linux~/.local/share/anyport/anygba/saves/
macOS~/Library/Application Support/anyport/anygba/saves/
  • Files are named <title>-<hash>.sav and hold the raw chip contents, the layout mGBA and most emulators use, so you can bring an existing save across.
  • A save is written about half a second after the game stops changing it, and on exit. The previous file is kept as .sav.bak.
  • --save-dir DIR uses another folder, --no-save turns saving off, and --save-type T overrides detection.

To remap, write the current mapping to a file and edit it:

<Title> --write-input anygba-input.ini
[keyboard]
A = X, Space
FastForward = Tab

[gamepad]
A = South
B = East

The game reads anygba-input.ini next to the program, then in the data folder above (one level up from saves), or the file named by --input. Buttons you leave out keep their default; a misspelled name stops the program with the file and line. Full reference: INPUT_MAPPING.md.

Per-game config

Some games need help the static analysis cannot work out alone. Pass a TOML file with --config game.toml:

[game]
title = "My game"
save = "flash128"       # none, sram, flash64, flash128, eeprom, eeprom512, eeprom8k

[[entry]]               # a function the analysis cannot see
addr = 0x08000100
mode = "thumb"

[[skip]]                # data inside a code area
start = 0x08001000
end = 0x08001200

Also available: code copied into RAM ([[ram_region]]), byte patches ([[patch]]) and replacing a function with your own C ([[replace]]). Unknown keys are errors. Full schema: GAME-CONFIG.md.

AI agents 0.2

An AI agent such as Claude can play and debug a game through anygba-mcp, an MCP server in the package's bin folder. Add it to your MCP client (Claude Code: claude mcp add anygba -- <path>/anygba-mcp), then turn on AI control in the game (menu Settings > AI control, or F10) or let the agent start the game with its launch tool.

  • The game listens on 127.0.0.1 only, with a random token in a file in your user folder.
  • Pressing any button gives you control back at once; Read-only agent limits agents to watching and debugging.
  • The play journal (Settings > Journal, or F11) records what the agent and you did, with snapshots and thumbnails, in your user folder only.

Tools, safety and the journal: AI-CONTROL.md.

Troubleshooting

The game runs slowly in places, and anygba-miss.log appeared

That code was not found by the static analysis and ran in the interpreter. Rebuild with the log to make it native:

anygba build game.gba --miss-log anygba-miss.log

Repeat after playing further if new addresses show up.

The program stops with an error naming an address

An unknown BIOS call, undefined instruction or unsupported hardware access stops the game on purpose rather than guessing. Some cases can be worked around with a per-game config. Please open an issue with the message (never attach the ROM).

The build fails because CMake or the compiler is missing

Check cmake --version (3.28 or newer) and that a compiler is installed (see Install). Use --cmake PATH or --generator NAME to point anygba build at a specific one.

The program says the ROM does not match

Each program accepts only the exact ROM it was built from (by SHA-256). Rebuild from the ROM you want to play.

A save file is rejected

A save whose size does not fit the game's chip stops the program instead of being overwritten. Check you copied the right file, or set --save-type.

A button does nothing

Check anygba-input.ini next to the program and in the data folder; an empty value unbinds a button.

FAQ

Where do I get games?

From your own cartridges. AnyGBA provides no ROMs, BIOS images or game assets and never will. Dump cartridges you own with a cartridge-dumping device, or use the many free homebrew games made for the GBA. Downloading commercial ROMs you do not own is copyright infringement in most countries.

Do I need a GBA BIOS file?

No. The BIOS is reimplemented in the runtime.

Can I share the program I built?

Only with people who own the game, because the ROM is embedded in it. Build with --no-embed to leave the ROM out; the program then takes it as its first argument.

Is this an emulator?

No. The game's code is translated to C and compiled before it runs. A small interpreter exists only as a fallback for code the analysis missed. See how it differs.

Should I use this instead of mGBA or VisualBoyAdvance?

For playing a large library today, a mature emulator is the safer choice. AnyGBA is for running a game as its own native program and for people interested in recompilation; it is young, and few games are verified.

Does it support save states, cheats or filters?

Not in {{version}}. They are coming in 0.2.
