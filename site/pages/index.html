Your GBA games, as native programs.

AnyGBA is a static recompiler. It reads a Game Boy Advance ROM that you dumped from your own cartridge, translates its ARM and Thumb code to C ahead of time, and builds a real Windows, Linux or macOS program from it. No emulator loop runs underneath.

How it differs from an emulator

An emulator (VisualBoyAdvance, mGBA)

Loads the ROM at run time and interprets or JIT-compiles every instruction while you play, inside one general-purpose program that runs any game. Mature, accurate, and the right choice for most people.

AnyGBA

Translates the whole game to C once, before it runs, and compiles it with your system's C compiler. The result is one program per game, with the BIOS, video, audio and input provided by a native runtime library. Code the analysis missed falls back to an interpreter and can be fed back in to become native on the next build.

The approach follows static recompilation projects for other consoles: the game becomes ordinary native code you can profile, patch in C, and run without any emulation core. More on the approach.

Why this exists

I grew up with the Game Boy Advance, and with VisualBoyAdvance on a family PC in primary school. AnyGBA is my way of giving something back to that childhood: bringing those games back to life, making them run better than they ever did on that old PC, and carrying the feeling forward.

Mình làm AnyGBA vì tuổi thơ, vì tình yêu với GBA và VBA từ những ngày tiểu học: để hồi sinh, cải thiện, bù đắp và tiếp nối tuổi thơ ấy.

  • Windowed play, audio, and real controllers are still untested on hardware: see known limits.
