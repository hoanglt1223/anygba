Features

What works in AnyGBA {{version}}, what is being built for 0.2, and what is not done yet. Details live in the README.

In {{version}}

Static recompiler

ARM/Thumb decoder, function discovery, and a C code generator. jsmolka's ARM, Thumb, memory and BIOS test ROMs pass as recompiled native code.

Trace feedback

Code the analysis missed runs in a fallback interpreter and is logged to anygba-miss.log. Rebuild with --miss-log and it becomes native.

HLE BIOS

Every SWI from 0x00 to 0x2A. Div, Sqrt and ArcTan match mGBA's HLE BIOS bit for bit; the decompressors reproduce data packed by grit. No BIOS image needed.

Video

Scanline renderer for all six video modes, 128 regular and affine sprites, windows, alpha blending, brightness, mosaic. 48 test pictures match mGBA pixel for pixel.

Audio

All four PSG channels and both DirectSound FIFOs, mixed at 32768 Hz. Test tones correlate with mGBA's output above 0.99.

Saves

SRAM, Flash 64/128 KB and EEPROM 512 B/8 KB, auto-detected, written safely with a backup of the previous file. Raw .sav files, compatible with most emulators.

One-command builds

anygba build game.gba produces a single program with the ROM embedded: .exe on Windows, a binary on Linux, an .app on macOS.

Controls

Keyboard and any SDL gamepad, remappable in anygba-input.ini. Hold Tab to fast-forward.

Per-game config

TOML files for extra entry points, RAM code, data to skip, byte patches, and whole functions replaced by your own C.

Coming in 0.2 in development

These features are being built now and are not in {{version}}. Names and details may change before release.

Speed-up

Fast-forward at fixed rates of 200%, 300% and 400%, on top of the unlimited Tab fast-forward.

Save states

Nine save-state slots per game, alongside the normal in-game saves.

Cheats

GameShark, Action Replay and CodeBreaker codes, with a browsable cheat menu: categories and pick-lists (for example, choosing a creature species from a list instead of typing a value).

AI agents

anygba-mcp lets an AI agent watch, play and debug a running game: screenshots, frame-accurate input, save states, cheats, named game variables, breakpoints and memory watches, plus a play journal so later sessions learn from earlier ones. Off by default, local only, and you can take over any time.

Graphics filters and upscaling

Nearest, bilinear and sharp-bilinear; Scale2x/3x/4x, Eagle, the 2xSaI family, hqx and xBR/xBRZ up to 6x; LCD grid, scanlines, CRT and LCD ghosting; GBA LCD colour, gamma and debanding; output at 720p, 1080p, 1440p, 4K or desktop size, switchable from the menu while playing.

Known limits in {{version}}

  • Windowed play, real audio devices, keyboard/gamepad input and audio-led pacing have only been tested headless on the development PC.
  • Linux and macOS packages are built and checked in CI, but the macOS .app has not been run on a Mac.
  • EEPROM saves are covered by unit tests only.
  • The BIOS sound driver calls and MultiBoot are stubs; most games use their own sound engine and do not call them.
  • No commercial game has been verified yet. Progress is on the compatibility page.
