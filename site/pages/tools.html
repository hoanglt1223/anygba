Tools

The AnyGBA package contains command-line tools in its bin/ folder. The text below is their --help output from {{version}}.

  • anygba: ROM to program
  • anygba-recomp: the recompiler
  • A generated game
  • anygba-shot: headless screenshots

anygba

Recompile, compile and package a ROM in one step. This is the tool most people need.

usage: anygba build <game.gba> [options]

Recompiles the ROM, compiles the result against the installed runtime, and writes
<Title>.exe (Windows), <Title> (Linux) or <Title>.app (macOS) with the ROM embedded.

  --config FILE      per-game config (docs/dev/GAME-CONFIG.md)
  --miss-log FILE    trace-feedback log from an earlier run (repeatable)
  -o, --output DIR   where the program goes (default: current folder)
  --work DIR         generated C and build files (default: <output>/<rom name>-build)
  --name NAME        program name (default: the game title)
  --prefix DIR       anygba install prefix (default: the folder above this program's bin/)
  --cmake PATH       cmake executable (default: cmake on PATH)
  --generator NAME   CMake generator (default: CMake's choice)
  --build-type TYPE  CMake configuration (default: Release)
  --no-embed         do not embed the ROM; the program then takes it as its first argument

anygba-recomp

The recompiler on its own: writes a C project you can inspect, edit, and build with CMake.

usage: anygba-recomp <rom.gba> [--config game.toml] [--miss-log FILE]... [--output dir] [--list]

  --config FILE   per-game TOML configuration
  --miss-log FILE runtime miss log; its addresses become entry points (repeatable)
  -o, --output    directory for the generated C project (default: recomp-out)
  --list          print discovered functions with disassembly instead of generating C
  --shards N      split the functions over exactly N funcs_NNN.c files
  -h, --help      show this help
  --version       show the version

The steps anygba build runs for you:

anygba-recomp game.gba --output game-src [--config game.toml]
cmake -S game-src -B game-src/out -DCMAKE_PREFIX_PATH=<prefix>
cmake --build game-src/out --config Release
game-src/out/Release/game game.gba

A generated game

Every program AnyGBA builds accepts these options.

usage: game [rom.gba] [options]

  rom.gba             the ROM this program was generated from; omit it when the ROM is embedded
  --headless          no window and no audio (SDL dummy drivers); runs unpaced unless --pace
  --pace              pace to real time (default with a window)
  --fast              do not pace
  --scale N           initial window size as a multiple of 240x160 (default 3)
  --frames N          stop after N frames
  --seconds S         stop after S seconds of wall-clock time
  --exit-on-idle      stop at the first branch-to-self and print the registers
  --dump-frame-hash   print the SHA-256 of the last frame (RGB555, little-endian) on exit
  --save-dir DIR      where the save file lives (default: the per-user data folder)
  --save-type T       none, sram, flash64, flash128, eeprom, eeprom512 or eeprom8k (default: config, else detect)
  --no-save           do not read or write a save file
  --input FILE        input mapping (default: anygba-input.ini next to the program, else in the data folder)
  --write-input FILE  write the current input mapping to FILE and exit
  --miss-log FILE     where to append addresses the recompiled code missed (default anygba-miss.log)
  --no-miss-log       do not write the miss log

anygba-shot

Runs a ROM in the interpreter without a window and writes screenshots, frame hashes, memory dumps or audio. It is built with the test suite; the screenshots on this site were made with it.

usage: anygba-shot ROM --frames N [--shot F:out.png] [--hash F] [--keys KEY:A-B] [--dump REGION:out.bin]
                   [--wav out.wav]
  REGION is ewram, iwram, io, palette, vram or oam, written after the last frame
  --wav writes all sound (32768 Hz stereo 16-bit)
anygba-shot homebrew.gba --frames 300 --shot 300:title.png --keys a:120-130
